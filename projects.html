Update: KonaTube

Nov 2026

I made an iPhone app! KonaTube is basically just mobile YouTube (m.youtube.com) in a window, with injected scripts that strip out Shorts and ads and keep audio playing in the background or with the screen locked. SponsorBlock is built in too (it's supposed to work, but idk).

The native part is about 200 lines of Objective-C; the rest is a list of blocking rules and five scripts, around 600 lines all together. I build it on Linux without Apple's SDK, so no Mac needed. For a while it kept logging me out of YouTube every time I closed it, until I made it back up the cookies.

Source is on github (AGPL-3.0), and the .ipa is under releases if you want to sideload it.

csweb

Oct 2026

Counter-Strike 1.6 running in a browser, from a single local HTML file. I made it so it would run on school Chromebooks, where you can't install anything. It uses the open-source Xash3D engine compiled to WebAssembly, and the maps, models and sounds come from your own copy of the game, so none of Valve's files are in the repo.

Online play kinda works, but it's finicky and breaks half the time. Players connect straight to each other over WebRTC, and there's a server list and YaPB bots. Browsers can't send raw UDP though, so you can't join real CS 1.6 servers, only other people running the page.

It's not public yet, so no link for now.
